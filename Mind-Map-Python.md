# 🐍 Carte Mentale Python — Domaines et Modules

```
Python
├─ 🧩 Base / Core
│  ├─ Types : int, float, str, bool, list, tuple, dict, set
│  ├─ Fonctions intégrées : len, range, enumerate, map, filter, zip, etc.
│  ├─ Méthodes spéciales : __init__, __str__, __add__, __len__, etc.
│
├─ 📂 Système & Fichiers
│  ├─ os : fichiers, dossiers, environnement, process
│  ├─ pathlib : gestion moderne des chemins
│  ├─ shutil : copier, déplacer, supprimer, espace disque
│
├─ 🕓 Dates & Temps
│  ├─ datetime : date, heure, timestamp, timedelta
│  ├─ time : mesures, sleep, horodatage
│
├─ 🔢 Math & Calcul
│  ├─ math : fonctions trigonométriques, logarithmes, constantes
│  ├─ random : nombres aléatoires, tirages, shuffle
│  ├─ decimal / fractions : précision et nombres rationnels
│
├─ 🌐 Réseaux & Web
│  ├─ socket : communication réseau
│  ├─ http / urllib / requests : accès web, API
│  ├─ json : sérialisation/désérialisation JSON
│
├─ 🧠 Système & Processus
│  ├─ sys : arguments, chemins, flux, version
│  ├─ subprocess : lancer commandes externes
│  ├─ platform : informations OS et hardware
│
├─ 🧩 Données & Sérialisation
│  ├─ pickle : sérialisation binaire
│  ├─ json : format texte JSON
│  ├─ csv : fichiers CSV
│  ├─ configparser : fichiers de configuration
│
├─ 🧩 Expressions & Textes
│  ├─ re : expressions régulières
│  ├─ string : constantes, manipulation texte
│
├─ 📦 Modules Avancés
│  ├─ argparse : ligne de commande
│  ├─ logging : journalisation
│  ├─ itertools : itérations avancées
│  ├─ functools : fonctions avancées, décorateurs
│
├─ 🖥️ Interfaces & GUI
│  ├─ tkinter : interfaces graphiques simples
│  ├─ curses : interface console avancée
│
├─ 📊 Data Science / Analyse
│  ├─ numpy : tableaux multidimensionnels
│  ├─ pandas : DataFrame, analyse de données
│  ├─ matplotlib / seaborn : graphiques
│
├─ 🤖 Intelligence Artificielle / ML
│  ├─ scikit-learn : machine learning
│  ├─ tensorflow / pytorch : deep learning
│
├─ 🕹️ Jeux
│  ├─ pygame : création de jeux 2D
```
